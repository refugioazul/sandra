Arquivos:

COMO TESTAR:
1. Extraia o ZIP.
2. Abra o arquivo index.html no navegador.

COMO PUBLICAR GRÁTIS NO GITHUB PAGES:
1. Crie uma conta em github.com.
2. Crie um novo repositório, por exemplo: refugio-azul.
3. Envie todos os arquivos desta pasta para o repositório.
4. Vá em Settings > Pages.
5. Em "Build and deployment", escolha "Deploy from a branch".
6. Selecione a branch main e a pasta /(root).
7. Salve. Em alguns minutos o GitHub mostrará o link público.
